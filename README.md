Run Locally

Clone the repository:

git clone https://github.com/chethanakuppala/chethana-portfolio.git
cd chethana-portfolio

Start a local server:

python3 -m http.server 8000

Open:

http://localhost:8000

You can also open index.html directly or use the VS Code Live Server extension.

Deploy with GitHub Pages

Open the repository on GitHub.

Go to Settings.

Select Pages.

Under Build and deployment, choose Deploy from a branch.

Select:

Branch: main

Folder: / (root)

Save the settings.

The website will be available at:

https://chethanakuppala.github.io/chethana-portfolio/
